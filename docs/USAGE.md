## 1. 认识 Publii-CN

Publii 是一款**桌面端静态站点生成器**：它在你的电脑上以可视化界面编辑内容，然后生成纯静态 HTML 文件，最后一键上传到服务器或代码仓库。相比 WordPress 这类服务器 CMS，静态站点更快、更安全、无需数据库维护。

Publii-CN 在保留这一切的基础上，专为中文用户做了增强：完整中文界面、WordPress 式分类栏目、两款中文主题、中文排版优化，以及更可靠的 GitHub 部署。

---

## 2. 安装与启动

### Windows
1. 从仓库 [Releases](https://github.com/66fxw/Publii-CN/releases) 下载 `Publii Setup 0.48.3.exe`。
2. 双击安装，按提示完成。
3. 从开始菜单或桌面快捷方式启动。

### 升级
直接下载新版本安装包覆盖安装即可，站点数据保存在独立目录（默认 `文档\Publii\`），不会被覆盖。

> macOS / Linux 版本暂未提供，可按 [`README.md`](../README.md) 的源码构建步骤自行打包。

---

## 3. 界面与语言设置

- 新安装的 Publii-CN **默认即为简体中文**，无需手动设置。
- 如需切换：进入「应用设置 → 基本设置 → 界面语言」，选择「简体中文」。
- 后台外观可在「应用设置 → 基本设置 → 界面风格」中切换：
  - **Publii**：默认浅色风格；
  - **WordPress 风格**：经典深色侧边栏 + 蓝色主色（切换后建议重启应用）。

---

## 4. 创建第一个站点

1. 启动后点击「新建站点」。
2. 填写站点名称，例如「科技迷」。
   - 站点名称保留中文作为显示名；
   - 实际目录名会自动转为拼音（如 `ke-ji-mi`），无需担心中文路径问题。
3. 选择作者、填写站点地址（如 `https://example.com`）。
4. 创建完成后进入站点视图。

> 中文文章标题、标签名、分类名同样会自动生成拼音 slug，保证网址是规范的 ASCII 路径。

## 5. 分类栏目（本分支特色）

上游 Publii 只有「标签」，Publii-CN 新增了与标签**相互独立**的「分类」体系，类似 WordPress 的分类栏目。

### 5.1 添加分类
1. 在站点视图右侧找到**快捷设置面板**（可折叠）。
2. 切换到「分类」标签页。
3. 输入分类名称（如「行业资讯」），点击添加。
   - 分类 slug 自动生成拼音（如 `hang-ye-zi-xun`）。
   - 分类数据保存在站点配置的 `categories` 数组中，无需数据库。

### 5.2 分类归档页与分类列表页
- 每个分类会自动生成一个归档页：`/categories/<分类slug>/`，列出该分类下的文章。
- 分类列表页：`/categories/`，汇总所有分类。
- 默认 URL 前缀为 `categories`，可在「网站设置 → 高级/URL 设置」中修改。

### 5.3 在文章中使用分类
在文章编辑器的右侧设置栏，展开「分类」分区，勾选该文章所属分类即可。

### 5.4 把分类加到菜单
1. 进入「网站设置 → 菜单」。
2. 新建菜单项，链接类型选择「分类栏目」或「分类列表」。
3. 选择具体分类，保存。

### 5.5 分类页的其他控制
在「网站设置 → SEO → 分类栏目 SEO 设置」中，可控制：
- 分类页 / 分类列表页的标题、描述、meta robots；
- 是否显示没有文章的分类（`显示无文章的分类`）；
- 是否关闭分类分页（`禁用分类分页`）。

## 6. 两款中文主题

在「网站设置 → 主题」中选择：

| 主题 | 适用场景 | 特点 |
|---|---|---|
| **china-corporate**（企业官网） | 公司官网、产品展示 | 商务深蓝、Hero 大图、服务卡片、关于我们、数据展示、CTA 行动区 |
| **china-news**（资讯博客） | 新闻、博客、个人站点 | 红橙主色、置顶头条、高密度图文列表、侧边栏热门与标签云 |

两款主题均：
- 使用中文优先字体栈（苹方 / 微软雅黑 / 思源黑体）；
- 针对中文优化了行高、断行、摘要显示；
- 输出 `lang="zh-CN"` 与 `og:locale="zh_CN"`，利于 SEO；
- 已适配分类栏目与分类归档页。

> 切换主题后建议重新生成一次站点，以确保分类页等新模板生效。

## 7. 写作与内容管理

- **文章**：左侧「文章」进入，支持 Markdown、可视化编辑器、自定义字段、标签、作者等（继承上游全部能力）。
- **页面**：左侧「页面」进入，适合关于、联系等独立页面。
- **标签**：左侧「标签」进入，与分类互不干扰。
- **摘要**：未手动填写摘要时，系统从正文自动截取；中文正文会按**字数**正确截断（上游按词截断，对中文无效）。

## 8. SEO 设置（含分类 SEO）

进入「网站设置 → SEO」，可配置全站与各类页面的搜索引擎优化项：

- 全站标题、描述、meta robots；
- 文章页、页面、标签页、作者页的标题 / 描述模板；
- **分类栏目 SEO 设置**（本分支新增）：
  - 分类列表页：标题、描述、meta robots；
  - 分类归档页：标题、描述（支持 `%categoryname`、`%sitename` 变量）、meta robots；
  - 显示无文章的分类、禁用分类分页。

常用的变量：
- `%sitename` — 站点名称；
- `%categoryname` — 分类名称（仅分类归档页）；
- `%tagname` / `%authorname` — 标签名 / 作者名（对应标签页 / 作者页）。

## 9. 预览与生成站点

- **预览**：在文章编辑器或站点视图点击「预览」，可在本地浏览器查看单篇文章 / 页面效果。
- **生成站点**：点击「生成站点」，Publii 会在站点目录下生成完整的静态文件（默认在 `文档\Publii\sites\<站点名>\output\` 或 `preview\`）。
- 生成过程中若报错，可在 `%APPDATA%\Publii\logs\sites\<站点ID>\` 下查看 `rendering-process.log` 与 `rendering-errors.log`。

> 若使用中文主题且报错 `ENOENT ... themes/china news/...`，说明使用的是旧版本 —— 请更新到已修复该问题的版本。

## 10. 部署到 GitHub 仓库

Publii-CN 支持将生成的静态站点上传到 GitHub 仓库（GitHub Pages）。本分支修复了**空仓库首次部署失败**的问题。

### 10.1 准备 GitHub 令牌（Token）
1. 在 GitHub → Settings → Developer settings → Personal access tokens 生成一个 Classic Token。
2. 勾选 `repo` 权限；若部署内容包含 `.github/workflows/` 下的工作流文件，还需勾选 `workflow` 权限。
3. 复制生成的 token（只显示一次）。

### 10.2 在 Publii 中配置
1. 进入「网站设置 → 服务器设置」。
2. 协议选择 **GitHub Pages**。
3. 填写：
   - 用户名（GitHub 用户名）；
   - 仓库名；
   - 分支（如 `main`）；
   - Token（粘贴上一步的令牌）；
   - 站点目录（可选，仓库内的子目录）。
4. 点击「测试连接」，确认通过。

### 10.3 部署
回到站点视图，点击「部署 / 上传」，Publii 会生成站点并通过 GitHub REST API 推送文件。

- **空仓库也可以直接部署**：本分支会自动创建分支引用并提交首次版本。
- 如果遇到 403 / 权限错误，请检查 token 是否包含 `repo`（及需要的 `workflow`）权限。

> 说明：请使用 **GitHub Pages** 协议（走 API，连通性好）。「Git」协议走 git-over-HTTPS，在某些网络环境下可能失败。

## 11. 中文特性说明

| 特性 | 说明 |
|---|---|
| 默认中文 | 新安装默认简体中文，老配置自动迁移一次 |
| 中文摘要 | 按字数截断，不再整段输出 |
| 拼音排序 | 文章 / 标签 / 作者 / 分类 / 站点名按 zh-Hans-CN 拼音排序 |
| 拼音 slug | 分类、文章、标签、作者中文名自动生成拼音 URL |
| 中文标点 | 「你好，世界」等不再产生粘连 slug |
| 中文字体 | 默认界面与主题均含中文优先字体栈，西文字体自动附中文 fallback |
| 中文排版 | 主题标题行高、断行、字距针对中文优化 |
| 中文 SEO | `html lang="zh-CN"`、`og:locale="zh_CN"` |

## 12. 常见问题

**Q：分类页显示空白 / 分类不显示？**
A：请确认使用的是修复后的版本（分类页容器高度问题已修复），并在「网站设置 → 主题」重新选择主题后重新生成站点。

**Q：中文文章网址是乱码或很长的编码？**
A：本分支会为文章、分类等生成拼音 slug。如果你的标题是纯 emoji 或纯标点，可能触发兜底 slug，建议标题包含实际文字。

**Q：GitHub 部署报 404？**
A：确认仓库名、用户名、分支填写正确；空仓库首次部署本分支已支持，若仍失败请检查 token 权限与仓库是否存在。

**Q：生成站点时报 `ENOENT ... china news/...`？**
A：这是旧版本主题名与目录名不一致导致的渲染问题，已在本分支修复，请更新到最新版本。

**Q：本分支和官方 Publii 是什么关系？**
A：本分支是社区二次开发版本，非官方发布，遵循 GPLv3 开源。官方项目见 <https://github.com/GetPublii/Publii>。
