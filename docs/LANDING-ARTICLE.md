我先把话放这儿：如果你只是想安安静静做个博客、企业站或资料站，现在还上 WordPress + 数据库 + 服务器那套，多少有点 heavy 了。

不是说 WordPress 不好——它对新手友好、生态成熟，这点没得黑。但问题也很现实：服务器要维护、数据库要备份、插件要更新、隔三差五还得应付安全漏洞（闪核网之前就报道过好几次 CVE，动不动 CVSS 9.8）。对于一个不折腾交互、只发内容的小站来说，这些成本纯属白交。

那换静态站点生成器？Hugo、Hexo、Jekyll 确实快、确实安全，但门槛也真不低：命令行、YAML、Git、主题魔改……不少人卡在第一步就放弃了。

有没有一种东西，既有 WordPress 那种可视化后台的省心，又能产出纯静态文件？

还真有。今天这篇就帮大家掰扯明白一个我最近在用的工具：**Publii-CN**——一个把"像 WordPress 一样可视化写站"和"纯静态站点的快与安全"捏在一起的桌面软件，而且是国内网友做的中文增强版，免费开源。

---

## 它到底是什么？

Publii 是一个**桌面端 CMS**：软件装在你电脑上，你在可视化界面里写文章、配主题，点一下"生成"，它就在本地吐出一套纯 HTML 静态文件，最后你把这些文件往服务器、GitHub、Netlify 上一丢就完事。

- 没有服务器 PHP，没有数据库；
- 生成的是纯静态文件，打开快、不怕 SQL 注入、不用天天打补丁；
- 离线也能写，联网了再一键上传。

而 **Publii-CN** 是在官方 Publii 基础上做的二次开发分支，专门补了中文用户最需要的几块。它不是换个语言包那么简单，是真的把中文场景从头捋了一遍。

---

## 中文用户最该关心的几点

### 1. 打开就是中文，不用自己折腾汉化

新装好默认就是简体中文界面，2085 条翻译键和英文包一一对应。不像有些工具汉化一半、菜单里中英混搭——这个是真·全中文。

### 2. 分类栏目：终于有 WordPress 那味儿了

官方 Publii 只有标签（tag），做资讯站、企业站时想按"栏目"归类文章就很别扭。

Publii-CN 补上了一套**独立分类体系**，跟标签互不干扰：

- 右侧快捷面板里直接增改分类；
- 每个分类自动生成独立归档页（`/categories/分类名/`）；
- 有分类汇总页，菜单里能直接挂分类链接；
- 分类页还能单独配 SEO 标题、描述、robots。

这对做行业资讯、企业官网的人来说，是刚需级的功能。

### 3. 两款中文主题，开箱能看

内置两款为中文场景做的主题：

- **china-corporate**：企业官网风，商务深蓝，Hero、服务卡片、关于我们、数据展示、CTA 一套齐；
- **china-news**：资讯博客风，红橙主色，头条 + 高密度图文列表 + 侧边栏热门。

两款都用了中文优先字体栈，行高、断行、摘要都按中文习惯调过，还带 `lang="zh-CN"` 和 `og:locale="zh_CN"`，SEO 细节也照顾到了。

### 4. 中文细节，是真的做了

这块最容易被忽略，但用起来差别很大：

- 文章、标签、作者、分类按**拼音排序**，不是按乱码一样的 Unicode 码位；
- 分类、文章的中文标题自动生成**拼音网址**（比如"新闻"→ `xin-wen`），不会变成一长串中文编码；
- 摘要按**字数**截断——官方版按空格分词，中文一整段没有一个空格，导致摘要要么全出要么没有，这里修好了；
- 「你好，世界」这种中文标点不会再把拼音粘成 `ni-haoshi-jie`，而是正确切成 `ni-hao-shi-jie`。

### 5. 部署到 GitHub 仓库，这次真能成

静态站最常见之一就是传 GitHub Pages。Publii-CN 修了两个很实际的坑：

- **空仓库首次部署**：以前新建仓库、目标分支还不存在时，推送直接 404 失败；现在会自动创建分支引用并提交第一个版本。
- **主题名带空格导致渲染崩溃**：比如主题显示名是「China News」、目录却叫 `china-news`，老版本会拼错路径报 ENOENT；现在按真实目录名处理。

> 建议用软件里的 **GitHub Pages** 协议（走 API），比 Git 协议在复杂网络环境下稳。Token 记得勾 `repo` 权限，如果传的工作流文件在 `.github/workflows/` 下，还要勾 `workflow`。

## 适合谁用？

- 想做博客、作品集、文档站的個人站长；
- 需要企业官网、但不想维护服务器和数据库的中小企业；
- 受够了 WordPress 安全告警、又嫌 Hugo/Hexo 太极客的用户；
- 想白嫖 GitHub Pages 免费托管、又要中文体验顺滑的人。

一句话：**想要 CMS 的省心，又想要静态站的安全和速度，还不想被英文和命令行劝退**——这个就是为你准备的。

## 怎么上手？

1. 去 GitHub Releases 下载 Windows 安装包（约 139MB），双击安装：
   **[下载 Publii-CN 安装包](https://github.com/66fxw/Publii-CN/releases/download/v0.48.3-cn1/Publii-CN-0.48.3-Setup.exe)**
2. 启动后默认简体中文，新建一个站点；
3. 在网站设置里选 `china-corporate` 或 `china-news` 主题；
4. 右侧面板加分类，写文章，点"生成站点"看效果；
5. 到服务器设置里配 GitHub Pages，一键上传。

完整使用文档在项目仓库里：
**[Publii-CN 使用文档](https://github.com/66fxw/Publii-CN/blob/main/docs/USAGE.md)**

静态站点这两年并不缺工具，但缺的是"中文用户拿来就能顺手用"的工具。Publii-CN 干的其实就是这件笨功夫：把汉化做全、把中文排版理顺、把分类和 SEO 这些国内用户常用的东西补齐，再把几个真实会踩的坑填掉。
