# 落地页文章导入 Gutenberg 编辑器说明

配套文件：[`LANDING-GUTENBERG.html`](./LANDING-GUTENBERG.html)

这份 HTML 使用 **WordPress 核心区块的标准序列化标记**（`<!-- wp:... -->` 注释），粘贴后会被 Gutenberg 识别为**原生可编辑区块**（标题、段落、按钮、分栏、表格、折叠面板等），而不是纯文本或一大块自定义 HTML。

---

## 推荐方式：代码编辑器粘贴（最可靠）

1. 在 WordPress 后台新建文章，进入 Gutenberg 编辑页。
2. 点击右上角的「**三个竖点 ⋮**」（选项菜单）。
3. 打开「**代码编辑器**」开关（Code editor）——编辑区会变成显示区块标记的文本框。
4. 用记事本 / VS Code 打开 `LANDING-GUTENBERG.html`，**全选复制全部内容**。
5. 回到代码编辑器文本框，**全选删除原有内容，粘贴**。
6. 再次点开右上角「⋮」，**关闭「代码编辑器」**，切回可视化视图。
7. 此时应看到完整排版的区块：Hero 标题、下载按钮、特性分栏、主题表格、更新记录、FAQ 折叠面板。
8. 检查顶部 Hero 里的两处链接（下载、GitHub）是否正确，按需微调，然后发布。

> 关键点：一定要通过「代码编辑器」粘贴。如果直接粘到可视化视图的段落里，区块注释会被当成普通文字，样式就丢了。

---

## 备选方式：作为经典 HTML 块粘贴

如果不想切代码编辑器，也可以：

1. 复制文件全部内容。
2. 在可视化编辑器中添加一个「**自定义 HTML**」区块（Custom HTML）。
3. 粘贴进去。

但这种方式下内容会作为一个整体 HTML 块存在，**不能逐段编辑**，样式依赖主题 CSS，效果不如推荐方式。仅作兜底。

---

## 区块清单（导入后应看到）

| 区块 | 用途 |
|---|---|
| Group（组） | Hero 区、下载 CTA 区（带背景色与内边距） |
| Heading（标题） | 主标题、各章节标题、更新记录的时间小标题 |
| Paragraph（段落） | 正文、链接、版权说明 |
| Buttons / Button（按钮组/按钮） | **下载按钮**、GitHub 按钮（带颜色、圆角、新窗口打开） |
| Columns（分栏） | 两列特性网格（6 项特色） |
| Table（表格） | 两款主题对比 |
| List（列表） | 中文细节、适合人群、更新记录条目 |
| Quote（引用） | 产品介绍、结语 |
| Separator（分隔线） | 章节分隔 |
| Details（折叠面板） | FAQ 常见问题 |

## 自定义与替换

- **下载按钮链接**：出现两处，均为
  `https://github.com/66fxw/Publii-CN/releases/download/v0.48.3-cn1/Publii-CN-0.48.3-Setup.exe`
  如需换版本，改完重新上传安装包后同步替换这里。
- **GitHub 主页 / 文档链接**：`https://github.com/66fxw/Publii-CN`
- **文章自身地址**：发布拿到地址后，回填到项目 README 的「中文介绍文章」处（本次另行处理）。
- **颜色**：按钮用 WordPress 默认调色板 slug（`vivid-red`、`midnight-blue`、`pale-ocean-blue`），若主题调色板不同，导入后可在右侧设置面板改颜色。
- **配图**：如需 Hero 图或主题截图，可在 Group 区块内追加「图像」区块，或设置 Group 的背景图片。

## 兼容性说明

- 标记使用 Gutenberg 核心区块，兼容 WordPress 5.8+；`Details`（折叠面板）区块在较新版本（WP 6.x+）可用，旧版会降级为普通内容，不影响其它部分。
- 中文引号与 `<code>` 内联代码均正常使用。
- 全部链接带 `target="_blank"` 与 `rel="noreferrer noopener"`，站外打开更安全。
